# QuotaOps

Open-source quota and capacity management for AI agents.

QuotaOps is being built to track usage limits, understand reset windows, forecast quota pressure, and help multi-agent systems route work to available capacity.

## Security posture

QuotaOps is designed to be local-first and credential-minimizing. Never commit API keys, OAuth tokens, session cookies, credentials, or local provider state to this repository.

Security issues should be reported privately as described in [SECURITY.md](SECURITY.md).
