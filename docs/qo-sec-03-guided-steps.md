# QO-SEC-03 — οδηγός βήμα προς βήμα

**Για:** τον ιδιοκτήτη του repository
**Χρόνος:** περίπου 40 λεπτά, σε 5 μικρά βήματα
**Μηχάνημα:** Windows 11

Ο αναλυτικός κατάλογος είναι στο `docs/qo-sec-03-windows-e2e-procedure.md`.
Αυτό εδώ είναι η σύντομη εκδοχή: κάνετε ένα βήμα, μου λέτε τι είδατε,
προχωράμε στο επόμενο.

---

## Τι αποδεικνύει αυτή η δοκιμή

Όλα τα αυτόματα τεστ μέχρι τώρα χρησιμοποιούν **ψεύτικο** φυλλομετρητή που
δεν συνδέεται πουθενά. Αποδεικνύουν ότι ο κώδικας ανοίγει και κλείνει
προγράμματα σωστά.

**Δεν αποδεικνύουν** ότι η εφαρμογή διαβάζει σωστά τα πραγματικά σας υπόλοιπα
από τον πάροχο. Αυτό χρειάζεται πραγματική σύνδεση, και η σύνδεση χρειάζεται
εσάς.

**Τι σημαίνει E2E:** «end to end», από άκρη σε άκρη. Δοκιμάζουμε ολόκληρη τη
διαδρομή — σύνδεση, συλλογή, εμφάνιση — όχι ένα κομμάτι της.

---

## Πριν ξεκινήσετε

**Φτιάξτε έναν αναλώσιμο λογαριασμό** Claude ή OpenAI. Όχι τον κανονικό σας.
Αν αυτό δεν γίνεται, πείτε το πριν ξεκινήσουμε αντί να χρησιμοποιήσετε τον
πραγματικό.

**Δεν θα μου στείλετε ποτέ:** κωδικούς, κωδικούς μιας χρήσης, cookies,
αρχεία προφίλ, tokens, ή αρχεία ιστορικού. Μόνο «πέρασε» / «απέτυχε» και
αριθμούς.

---

## Βήμα 1 — Αυτόματος έλεγχος (5 λεπτά, χωρίς σύνδεση)

Ανοίξτε PowerShell στον φάκελο του repository και τρέξτε:

```powershell
powershell -NoProfile -File .\scripts\e2e-report.ps1
```

**Τι κάνει:** τρέχει μόνο του ό,τι δεν χρειάζεται άνθρωπο — τεστ, builds,
έλεγχο δικαιωμάτων αρχείων, έλεγχο ότι δεν μένουν ανοιχτοί φυλλομετρητές.

**Στείλτε μου:** την τελευταία γραμμή, που μοιάζει κάπως έτσι:

```
Automated: 13 PASS, 0 FAIL, 0 SKIP, 0 INCONCLUSIVE. Manual outstanding: 7.
```

**Τι σημαίνουν:** `PASS` πέρασε. `FAIL` απέτυχε. `SKIP` δεν έτρεξε γιατί
έλειπε κάτι. `INCONCLUSIVE` δεν μπόρεσε να ελεγχθεί — **δεν** σημαίνει
«εντάξει». Αν δείτε `FAIL`, σταματήστε εκεί και στείλτε μου τη γραμμή.

---

## Βήμα 2 — Πρώτη σύνδεση (10 λεπτά)

```powershell
npm run collector:setup -- add claude test-1 "Αναλώσιμος"
npm run collector:setup -- login test-1
```

Θα ανοίξει παράθυρο φυλλομετρητή. **Συνδεθείτε εκεί** με τον αναλώσιμο
λογαριασμό. Μετά:

```powershell
npm run collector:setup -- collect test-1
```

**Στείλτε μου:**
- Άνοιξε παράθυρο και σας άφησε να συνδεθείτε; ναι / όχι
- Εμφανίστηκαν νούμερα υπολοίπου που φαίνονται λογικά; ναι / όχι
- Είδατε κωδικό ή token στην οθόνη; **αυτό θα ήταν σφάλμα** — ναι / όχι

---

## Βήμα 3 — Καθάρισμα διεργασιών (3 λεπτά)

**Αμέσως μόλις τελειώσει** η συλλογή:

```powershell
powershell -NoProfile -File .\scripts\windows-browser-processes.ps1
```

**Στείλτε μου και τους τέσσερις αριθμούς.** Περιμένουμε μηδενικά.

**Γιατί έχει σημασία:** όταν η εφαρμογή ανοίγει φυλλομετρητή για να διαβάσει
τα υπόλοιπα, πρέπει να τον κλείνει μετά. Αν μένουν ανοιχτοί, τρώνε μνήμη και
κρατάνε ζωντανή τη σύνδεσή σας με τον πάροχο χωρίς λόγο.

Ο παλιός έλεγχος εδώ ήταν **λάθος** — έψαχνε στη διαδρομή του προγράμματος
Chrome αντί για το προφίλ, οπότε έβγαζε πάντα μηδέν ό,τι κι αν συνέβαινε.
Τον διόρθωσα· τώρα μετρά αληθινά.

---

## Βήμα 4 — Λήξη σύνδεσης (10 λεπτά)

Αποσυνδεθείτε από τον λογαριασμό **μέσα από την ιστοσελίδα του παρόχου**,
στο ίδιο προφίλ φυλλομετρητή. Μετά:

```powershell
npm run collector:setup -- collect test-1
```

**Στείλτε μου:** τι ανέφερε.

**Το σωστό:** «login_required» ή κάτι αντίστοιχο.

**Το λάθος:** `0%`, «διαθέσιμο», ή τα παλιά νούμερα σαν να είναι φρέσκα.
Αν δείτε κάτι τέτοιο είναι **σοβαρό** και σταματάμε εκεί — σημαίνει ότι η
εφαρμογή επινοεί δεδομένα όταν δεν ξέρει.

---

## Βήμα 5 — Η εφαρμογή (10 λεπτά)

```powershell
npm run collector:start
```

Σε δεύτερο παράθυρο PowerShell:

```powershell
node node_modules\electron\install.js
node_modules\electron\dist\electron.exe desktop\electron-ipc
```

**Στείλτε μου:**
- Άνοιξε παράθυρο εφαρμογής; ναι / όχι
- Φαίνονται τα δεδομένα του λογαριασμού; ναι / όχι
- Το εικονίδιο στο tray (κάτω δεξιά) ανοιγοκλείνει το παράθυρο; ναι / όχι
- Με «Quit» από το tray, κλείνουν όλα; ναι / όχι

**Τι είναι το tray:** η περιοχή εικονιδίων κάτω δεξιά στη γραμμή εργασιών.
Η εφαρμογή ζει εκεί όταν κλείνετε το παράθυρο, ώστε να συνεχίζει να
παρακολουθεί χωρίς να σας ενοχλεί.

## Τι μου στέλνετε στο τέλος

Ένα σχόλιο στο PR #20 σε αυτή τη μορφή:

```
Βήμα 1: 13 PASS, 0 FAIL
Βήμα 2: σύνδεση ναι, νούμερα λογικά ναι, κωδικός στην οθόνη όχι
Βήμα 3: 0 / 0 / 0 / 0
Βήμα 4: login_required
Βήμα 5: παράθυρο ναι, δεδομένα ναι, tray ναι, quit καθαρό ναι
```

Αν κάτι αποτύχει, γράψτε το με δικά σας λόγια. **Μην** αντιγράψετε μεγάλα
κομμάτια εξόδου — μπορεί να περιέχουν διαδρομές ή στοιχεία που δεν πρέπει να
δημοσιευτούν.

---

## Αν κάτι πάει στραβά

Σταματήστε στο βήμα που απέτυχε και πείτε μου τι είδατε. Δεν χρειάζεται να
το διορθώσετε ή να καταλάβετε γιατί — αυτό είναι δική μου δουλειά.

Το μόνο που δεν πρέπει να γίνει είναι να προχωρήσουμε παρακάμπτοντας ένα
αποτυχημένο βήμα, γιατί τότε το τελικό «πέρασε» δεν θα σημαίνει τίποτα.
