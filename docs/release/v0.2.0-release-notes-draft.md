# QuotaOps 0.2.0 — release notes (DRAFT, not published)

> Draft for review. Not a published release. Publishing requires the release
> owner's approval and a signed installer.

## Who should install this

Everyone who installed the unsigned **QuotaOps 0.1.0** test build, and anyone
installing QuotaOps on Windows for the first time.

## What was wrong in 0.1.0

**Quit could appear to do nothing.** In 0.1.0, QuotaOps checked accounts in a
browser window that was minimized and moved off-screen. Windows still switched
to that window during every check. If the tray menu was open at that moment,
it closed, and a click on **Quit** was lost. Keystrokes typed during a check
also went to that hidden window. When Quit did arrive while a check was
running, QuotaOps could take up to 45 seconds to close, with its window and
tray icon still visible.

**Claude accounts showed "unsupported".** Claude asks some automated browser
sessions to "Verify you are human". 0.1.0 did not recognise that page
(especially in non-English Windows) and reported "unsupported", then tried
again every five minutes.

## What changed

- **Background checks never open a window.** Scheduled checks run without any
  window, so they cannot take focus, close menus or receive your typing.
- **Visible refresh only when you ask.** Tray → **Refresh with visible
  browser...** asks first, then opens one window per account and closes it.
- **Quit is immediate.** The window and tray icon disappear at once; QuotaOps
  stops any running check and exits, normally in under a second. Nothing is
  left running and port 4317 is released.
- **Claude verification is recognised in any display language.** QuotaOps
  shows **Manual verification required** instead of "unsupported", stops
  retrying that account in the background (at most once a day), and never
  answers the check for you.
- **Manual verification from the tray.** Tray → **Needs your attention →
  Manual verification required: <account>...** opens that account's own
  browser profile in normal Chrome or Edge. Complete the check, close the
  window, and QuotaOps checks the account again.
- **No false "synced" time.** If no account could be read, the dashboard no
  longer shows a fresh sync time. Last known values stay visible, marked as
  old; nothing is replaced by 0 %.
- **Lower memory.** Idle memory drops from about 319 MB to about 212 MB
  (software rendering; browser automation loaded only when first needed).

## Known limitations

- QuotaOps needs Google Chrome or Microsoft Edge installed.
- Claude may keep asking for verification of automated sessions. Then
  QuotaOps cannot read that account in the background; use **Refresh with
  visible browser...** after verifying, or enter values manually.
  *(Final wording depends on the owner's real-account validation.)*
- The visible refresh takes focus for about 15 seconds per account.
- There are no automatic updates. Install each new version yourself.

## How to install

1. Quit QuotaOps 0.1.0 from the tray, if it is running.
2. Download `QuotaOps-Setup-0.2.0-x64.exe` and `SHA256SUMS.txt` from the
   GitHub Release page.
3. Check the file: `Get-FileHash .\QuotaOps-Setup-0.2.0-x64.exe -Algorithm SHA256`
   must match `SHA256SUMS.txt`, and `Get-AuthenticodeSignature` must show
   `Valid` with the publisher named on the release page.
4. Run the installer. It installs for your user only; no administrator rights.
   Your accounts, browser profiles and settings in `%USERPROFILE%\.quotaops`
   are kept.

## Uninstalling

Use Windows Settings → Apps. Uninstalling keeps `%USERPROFILE%\.quotaops`
(accounts, browser profiles, local token). Delete that folder yourself if you
want them gone.
